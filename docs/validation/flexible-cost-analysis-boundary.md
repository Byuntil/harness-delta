# Flexible cost analysis boundary

The flexible workflow provides descriptive standardized estimated cost. It does
not estimate actual bills, subscription savings, or labor cost. Original task
assignment defines each arm; realized model and effort are descriptive outcomes.
Post-assignment model weighting is unsupported because it would remove part of
the policy effect under study.

Real allocation, complete cost and inference require separate evidence. Source
readiness binds a code-owned evidence ID to exact product/version, profile,
semantics digest and validation kind. The production source and analysis
registries are empty. Synthetic coverage cannot authorize real allocation.
Coverage decisions are recomputed from scoped facts, never accepted from a user
boolean. Task identity and declared followup windows must match. Operational
readiness alone cannot certify a complete request universe or valid inference.

The existing bounded integer studies cover at most four tasks and a token grid
of 0, 1 and 2. Their oracle checks are preserved. They provide no validation for
continuous monetary outcomes, repeated tasks within a person, or flexible costs.
Unknown quality, incomplete followup and deleted cohorts remain inconclusive.

A separate method design must preregister the following before implementation or
registration:

- Continuous monetary outcomes, finite precision and independent arithmetic oracles.
- Repeated tasks within assignees, block/time effects, complete and incomplete blocks.
- Differential missingness, failed and aborted tasks, and the original assignment denominator.
- Relative change with zero baseline cost and empty arms.
- Quality noninferiority and missing quality outcomes.
- Selective interim viewing, stopping rules and interference assumptions.
- Independent type-I error, interval coverage and precision oracles, acceptance
  thresholds and failure stopping conditions across the declared scenario grid.

No numeric calibration thresholds are supplied here. They must be selected and
approved in that method design. Failure or missing evidence leaves inference
unavailable; it never falls back to the older integer study. Source conformance
and a real experiment also require separate user authorization.
