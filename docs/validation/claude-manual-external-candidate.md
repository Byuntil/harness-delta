## Small contract

- `manualClaudeHandoff(invocation)` builds only a private fixed command: exact pinned2.1.288 binary, `claude-sonnet-5-5`/high, one print-mode turn, no tools/MCP, reviewed settings/append-file paths and fresh session UUID. It writes or executes nothing. The task prompt comes through stdin, never an argument.
- `prepareManualClaudeCandidate(store, options)` verifies the binary read-only, checks the registered canonical project and private0700 workspace outside it, starts the existing authenticated loopback gateway and prepares existing ephemeral settings/metadata-hook mediator files. It returns the handoff, state, one-time explicit `selectProcess(pid)` and `dispose()`, with no native run/spawn handle. Actual native preparation and metadata permission need separate approval. Preparation does not execute or activate a hook.
- `createManualClaudeReceiver()` reuses the parent-only coordinator/gateway. Authentication, registered scope, startup hook/logs and trusted process proof precede trace decoding. Its one private preparation bind resolves generated file paths before any startup; identity/runtime cannot change. Missing selected PID stays pending; mismatches revoke with a sanitized gap.
- `readManualClaudeProcess()` is a qualification-only macOS reader for the selected PID. Fixed `ps`/`lsof` commands compare exact known configuration argv, mapped executable, start identity and bounded binary/settings/instruction hashes, with a second identity check. It never reads process environment or discovers transcripts. Whitespace paths and ambiguous/changed argv are refused. These actual OS probes have not been run.
- First verified callback occurs once. Its timestamp bounds trace admission; older buffered spans are excluded and cannot be backfilled. Native process drift, task generation/pause, forbidden children, bad credentials and repeated requests fail before another decoder boundary. Stopping the receiver does not kill the user's native process.

Evidence is `native_process_flags_and_files_observed`, with `native_context_evidence: unverified` and tool compliance unavailable. Actual flags/file hashes prove supplied invocation inputs; they do not prove the native system context loaded them. No prompt, response, private argv/path or raw instruction bytes enter measurement evidence.
