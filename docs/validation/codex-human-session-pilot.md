# Collaborative Codex ordinary-session pilot

This isolated functional pilot collects candidate source evidence while a person
owns ordinary Codex startup, input, child creation and exit. It is not native
production admission, an automated qualification run or a real experiment. No
process owner, execution intent, model launcher or billed-request budget is added.
Codex 0.160.0 is the candidate; Claude remains qualification-pending.

Use a separately reviewed setup whose frozen protocol has purpose
`functional_pilot` and exactly one source profile:
`codex / 0.160.0 / codex-01600-ordinary-human-pilot`. Preserve native `codex`
provenance. Ordinary allocation, activation and adapter execution stay gated;
only assignment/configuration preparation may use this candidate. Production
source evidence and `bindingSourceSupported` remain unchanged. Costs are partial
and inference is unavailable.

Before touching a real project, review one concrete scope: canonical project and
one task, collection end condition, exact managed instruction/portable skill/hook files
and their preimages, exact private receipt directory and allowed source roots,
local UI origin and candidate binary/version. Approve installation and any exact
project trust handling separately from preparation. Never replace global hooks,
expand to another folder or scan session history. A receipt permits only its exact
source path, verified header and parent relation; source roots are containment
checks, not permission to enumerate native histories.

The existing `hm ui` command has two explicit local phases:

```sh
hm --db <measurement.sqlite> ui --setup <reviewed-ui.json> \
  --metadata <private-ui.sqlite> --port <port> --pilot-task <task-id>
```

This preparation phase reads task/configuration metadata and shows
`native_pilot_preparation_only`. Apply/reload can verify the reviewed managed
configuration. It cannot connect or read native sources. After exact installation
and source-scope authorization, stop that server and start the same command with
`--pilot-observe`. A browser request or manifest alone cannot enable observation.
For explicitly authorized collection until user stop, add `--pilot-until-stop`
while the task is inactive. This registers durable collection authority separately
from the frozen comparison follow-up. Restart preserves that authority; it never
resumes collection automatically. Omit the flag for legacy bounded collection.
New ordinary UI tasks with a configured session-binding source use explicit-stop
collection. Source admission remains a separate gate. Automated qualification
retains its original deadline and owned execution budgets.
The process-local capability pins the Store, one task, concrete Codex provider,
project and frozen candidate protocol. Other task actions and legacy ticket/link/
collect routes are disabled in pilot mode.

The UI shows `native_unverified_pilot` throughout observation. Start a fresh
ordinary Codex in the approved project after the observer starts. Invoke the
installed `$harness-connect` once with the selected origin/project/task and the
current trusted SessionStart receipt. A fresh receipt cannot turn an older resumed
source file into a fresh root: metadata birth time must follow observer startup.
Keep the user-selected model and effort as test conditions, not product defaults.
The collector permits one parent and two verified direct children, depth one.
Ambiguous, excess, nested or changed identities stop observation before their
usage bodies are read. They do not terminate the user's agent.

Inspect each session and the observed sum. Pause fences source reads, including
pending reads and child discovery. Usage while paused is unknown to the observer
and remains excluded when resuming. Resume rechecks preparation/window and pins
the same complete root identity using the retained actual receipt. UI restart
requires explicit resume and a new baseline. No historical interval is backfilled.
Pause stops source reads until explicit resume. Completion pauses the collector
before finalizing the human outcome. Revocation permanently blocks collection
for this task, including after restart. None of these actions terminates Codex.
Explicit-stop descriptive totals include later observed usage while comparison
outcome eligibility retains the original follow-up deadline. Neither paused gaps
nor historical usage are backfilled.

The person exits Codex. Complete the active final observation before pausing when
possible; otherwise mark final usage unverified. Pause, assess the human outcome,
reload and compare the persisted family/partial totals. Remove only the exact
installed artifacts/trust entries under the reviewed restoration procedure. A
successful synthetic regression or source-free Chrome check is not an actual
native pilot pass. Actual evidence must separately prove skill/hook loading,
materialized root/two-child sources, own request attribution, replay behavior,
pause/resume exclusion and the final human outcome. Admission requires an
independent review of that evidence and a separate code-owned registration change.

## Observed functional result and remaining limits

A human-operated pilot on 2026-10-07 observed one parent and two automatically
linked direct children, per-session own usage, updated family totals, explicit
collection completion, human success assessment and persisted results after UI
reload. The parent and first child used `gpt-6.1-sol/high`; the second child used
`gpt-6-astra/high`. Their observed request counts were 142, 92 and 16 respectively,
for 250 requests and a partial reference-rate estimate of USD 6.3399084.
This mixed-model descriptive result does not satisfy an all-Sol qualification.

Initial unobserved context, partial parent usage and the final unobserved interval
remain explicit. Complete native coverage, complete task cost and actual
intermediate pause/resume exclusion were not verified. Human work success does
not establish native source qualification. Claude family collection was not
measured in this pilot. Ordinary production admission and inference remain closed;
synthetic pause/resume regressions do not replace the missing actual observation.
The human exited the native session, collection stopped, temporary installation
was removed under the reviewed restoration procedure and the local observer shut
down. Private source files, project paths, session identifiers and operational
evidence are excluded from this public report.
